Az IsAuthenticated csak azt ellenőrzi, hogy a felhasználó belépett-e. Nem ellenőrzi, hogy az állat az övé-e.

A frontend tulajdonosválasztójával valaki akár más tulajdonoshoz is hozzáadhat állatot.
Ajánlott megoldás
Az Owner modellt össze kell kapcsolni a Django felhasználóval:
from django.conf import settings

class Owner(models.Model):
    user = models.OneToOneField(
        settings.AUTH_USER_MODEL,
        on_delete=models.CASCADE,
        related_name="owner_profile"
    )
Ezután a PetViewSet mindig a bejelentkezett felhasználóhoz tartozó állatokat adja vissza:
def get_queryset(self):
    if self.request.user.is_staff:
        return Pet.objects.all()

    return Pet.objects.filter(
        owner__user=self.request.user
    )
A DRF hivatalosan is a get_queryset() felülírását ajánlja a bejelentkezett felhasználó szerinti szűréshez. DRF filtering dokumentáció
Új állat létrehozásakor se a frontend által küldött owner ID legyen a döntő. A backend automatikusan állítsa be:
def perform_create(self, serializer):
    serializer.save(
        owner=self.request.user.owner_profile
    )
Így a felhasználó nem tudja átírni a kérésben az owner ID-t, és más tulajdonoshoz állatot létrehozni. A DRF külön kiemeli, hogy létrehozásnál a jogosultságot serializerben vagy perform_create() segítségével kell ellenőrizni. DRF permissions dokumentáció



------Hogy az admin mindent lásson, user ne----------
Igen, erre teljesen van lehetőség. A backend a request.user.is_staff vagy request.user.is_superuser alapján eldöntheti, hogy minden állatot vagy csak a sajátokat adja vissza.
A PetViewSet logikája:
def get_queryset(self):
    user = self.request.user

    if user.is_staff:
        return Pet.objects.all()

    return Pet.objects.filter(
        owner__user=user
    )
Így ugyanaz a végpont eltérő adatokat ad:
Normál felhasználó → csak a saját állatai
Admin/staff          → minden állat
Új állat létrehozásánál is lehet különbség:
def perform_create(self, serializer):
    if self.request.user.is_staff:
        serializer.save()
    else:
        serializer.save(
            owner=self.request.user.owner_profile
        )
Így az admin kiválaszthatja a tulajdonost, a normál felhasználó viszont nem írhatja át.
Ugyanez alkalmazható a többi ViewSetre foglalásoknál példáúl:
def get_queryset(self):
    if self.request.user.is_staff:
        return Appointment.objects.all()

    return Appointment.objects.filter(
        pet__owner__user=self.request.user
    )
